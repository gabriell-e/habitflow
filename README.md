# HabitFlow

Proyecto individual de Programación VI de la Universidad del Norte (UniNorte). La fase inicial contiene la navegación Ionic Angular standalone entre Hoy, Hábitos y Progreso. La aplicación todavía no consume datos.

## Desarrollo

Stack inicial con Ionic Angular 9.0.8, Angular 21.2.25 (LTS), TypeScript 5.9.3 e Ionicons 8.1.0.

Con Node.js 24 LTS y npm, ejecutar:

```sh
npm ci
npm start
```

Para comprobar los tipos y compilar para producción:

```sh
npm run typecheck
npm run build
```
